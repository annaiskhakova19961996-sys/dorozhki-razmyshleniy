# Дорожки размышлений

Адаптивная образовательная игра на русском языке. Иллюстрации состоят только из геометрических фигур, дорожек, букв и предметов; персонажей и живых существ нет.

## Что работает

- 6 разделов, 18 заданий, 54 вопроса с пояснениями.
- Проверка ответов, лучшие результаты и звёзды без повторного начисления за тот же результат.
- Цель дня: 3 разных задания; недельный календарь активности.
- 6 значков достижений.
- Локальный дневник размышлений, до 100 заметок по 1000 символов. При превышении лимита удаляется самая старая заметка.
- Сохранение прогресса в localStorage, обработка недоступного хранилища.
- Мобильная навигация, адаптивные карточки, управление с клавиатуры, поддержка reduced motion.

## Запуск

Сборка и зависимости не нужны. Из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Для публикации подойдёт статический хостинг с HTTPS. Домен и публикация в этой версии не настроены.

## Файлы

- `index.html` — каркас интерфейса и базовая Content Security Policy.
- `style.css` — десктопная и мобильная версии.
- `data.js` — вопросы, ответы и пояснения.
- `app.js` — игра, SVG-иллюстрации, прогресс, дневник.
- `icon.svg` — собственный логотип.
- `AUTH-PLAN.md` — план настоящей авторизации.

## Ограничения первой версии

Это гостевая версия, а не система защищённых аккаунтов. Вход по почте, облачная база и синхронизация пока не подключены. Кнопка «Войти» объясняет состояние и не собирает данные.

localStorage не является защищённым хранилищем: данные доступны пользователям того же браузерного профиля и могут быть изменены вручную. Очистка браузера удаляет прогресс. Правильные ответы доступны в исходном коде: приложение предназначено для обучения, а не аттестации. При подключении общего рейтинга проверку результатов следует перенести на сервер.

Нет внешних шрифтов, аналитики, трекеров, сетевых запросов, платежей или вымышленных пользовательских рейтингов. Счётчики отражают локальные результаты.

Для реального приёма пользователей необходимо реализовать и проверить пункты из `AUTH-PLAN.md`.
